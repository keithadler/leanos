leanos: a short guide

The dock
  Notes     a note that is saved to the SD card as you type
  Files     the files on the card; click one to read it, Delete removes it
  Terminal  commands; type help
  Settings  the background, the time zone, and the Raspberry Pi's speed and light
  Security  what every program's boot check found, and what is proved
  Apps      every program, built in or on the card, with its icon; click one to start it

The leanos menu
  Click the logo at the top left: Restart, or Shut down.

Windows
  Drag a window by its title bar. Its three buttons, at the top left:
  red       close it (a program with one window stops)
  yellow    minimize it: it leaves the screen, and its program keeps running; the dot
            under its icon in the dock turns amber. Click that icon (or `run` it again
            in Terminal) to bring it back, where it was, in front.
  green     zoom it: to the middle of the screen, in front; click again to put it back.
            Windows keep their size: a program draws its window at one size.
  Ctrl+O    the next window: the one in front goes to the back, and keys go to the one
            that comes to the front. Press it again to go through them all.
  The Window menu, in the menu bar after Edit, has Minimize, Zoom and Next window.

Copy and paste
  Ctrl+C    copy from the window in front (or Edit, Copy: Edit is in the menu bar,
            after the window's name)
  Ctrl+V    paste into the window in front (or Edit, Paste)

  What each program copies, and where a paste goes:
  Notes     the whole note; a paste goes at the end
  edit      the whole file (its first 4 KiB); a paste goes in at the cursor
  Terminal  the command line you are typing, or, when it is empty, what the last
            command printed; a paste goes onto the command line at the cursor, line
            breaks as spaces, so it never runs anything until you press Return
  Other programs do not answer a copy, and the clipboard stays as it was.

  Text moves between programs only by your hand. The display server keeps what you
  copy (up to 4 KiB of plain text, until leanos restarts). It asks the window in front
  for its text only when you press Ctrl+C, and takes the answer only from that window,
  within 2 seconds; it hands the text only to the window in front, when you press
  Ctrl+V. No program can read the clipboard, or put text on it, by asking.

  In the browser console, Ctrl+C, Ctrl+V and Ctrl+O are leanos's (Cmd+V on a Mac types the
  host's clipboard as keys). Under make run, your terminal's Ctrl+C stops QEMU itself.

Terminal
  ls, cat FILE, write FILE TEXT, rm FILE    files on the card (ls -a: icons too)
  mkdir FOLDER, cd FOLDER, cd .., pwd       folders
  mv FROM TO                                move or rename, in one step
  cp FROM TO                                copy a file (TO may be a folder)
  head, tail [-n N] FILE                    its first or last N lines (10 if not said)
  wc FILE                                   its lines, words and bytes
  grep [-i] TEXT FILE...                    the lines that hold TEXT (-i: in any case)
  find [FOLDER] [NAME]                      every file and folder under FOLDER, or those
                                            whose names hold NAME (16 folders down, 100
                                            names at most)
  df                                        the card's size, and what is used and free
  fill FILE KB CHAR, verify FILE            a big test file, and checking one
  ip, ping HOST, get http://URL [FILE]      the network (a USB network adapter)
  date, ntp [HOST]                          the time in your zone and UTC (set by ntp)
  run PROGRAM [FILE...]                     start a program from the card, giving it
                                            those files, 7 at most (and its own folder,
                                            apps/NAME)
  ps                                        every program slot, and what runs in it
  kill SLOT                                 stop a program from the card (10 to 15), answering or
                                            not, and take back the files it was given
  whoami, caps, boot, uptime                what the kernel says about this program
  tour                                      why leanos is harder to attack than Linux

  Up, Down      the commands you ran before (the last 32; history lists them), and back to
                the line you were typing
  Left, Right   move along the command line; what you type goes in at the cursor
  Tab           complete a command's name, or a file or folder name (a folder gets a /);
                when several match, Tab completes what they share and a second Tab lists them

Programs on the card
  tour    the guided tour: each page really tries an attack
  calc    a calculator: type 2+3*4 and press Enter
  snake   the arrow keys steer; space plays again
  life    Conway's Game of Life; space pauses, a click adds a cell, r reseeds
  tiles   2048: the arrow keys slide the tiles
  clock   the time in your time zone (until a time server answers, how long the Pi has been up)
  hello   the smallest program
  fuzz    20,000 system calls with made-up arguments, each answer checked
  edit    a text editor: run edit FILE gives it that file; it saves by itself
  web     a text web browser: run -net web lets it use the network

Every program from the card runs in an open slot: it gets its own memory and a window,
and nothing else, whatever it was written to do. Up to six run at once.
